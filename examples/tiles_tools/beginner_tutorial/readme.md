# Beginner Tutorial

**Keywords:** Tutorial, ECS, Grid Movement, tiles_tools

A step-by-step introduction to `tiles_tools`' core concepts, built around a small dungeon-explorer: a player moves around a grid, collects items, and encounters enemies. It walks through spawning entities in the ECS `World`, positioning them with a coordinate system, and wiring up the basic systems a tile-based game needs, aimed at newcomers to the crate rather than showcasing an advanced feature.
