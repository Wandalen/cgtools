# Game Systems Demo

**Keywords:** Turn-Based, State Machine, Resource Management, Quests, tiles_tools

This demo integrates several of `tiles_tools`' higher-level game systems at once: turn-based management with initiative and action points, a game state machine with transitions and phases, resource management (health/mana/experience), a quest system with objectives and rewards, and status effects layered on top.
