# Serialization Demo

**Keywords:** Serialization, Save/Load, JSON, RON, Bincode, tiles_tools

This demo exercises `tiles_tools`' save/load functionality: game-state serialization and deserialization across three formats (JSON, Binary, RON), configuration management and persistence, save-file management with metadata, version-compatibility checking, and compression support. Requires the crate's `serialization` feature, which pulls in `serde_json`/`bincode`/`ron` alongside `serde` itself.
