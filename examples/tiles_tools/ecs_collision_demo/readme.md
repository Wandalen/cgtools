# ECS Collision Demo

**Keywords:** ECS, Collision Detection, Spatial Queries, tiles_tools

This demo showcases `tiles_tools`' enhanced ECS collision systems: collision detection between entities, collision resolution via separation, and circular/line/rectangular spatial queries, including team-based filtering so allies and enemies can be queried separately.
