# Event System Demo

**Keywords:** Events, Pub/Sub, Decoupling, tiles_tools

This demo drives `tiles_tools`' event system: publishing and subscribing to events, event priorities and consumption, the built-in game events (movement, health, collisions), event statistics/performance monitoring, and auto-unsubscribing listeners — showing how game logic can communicate without direct coupling between systems.
