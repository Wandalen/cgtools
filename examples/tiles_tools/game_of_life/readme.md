# Game of Life (tiles_tools)

**Keywords:** Cellular Automata, ECS, Coordinate Systems, tiles_tools

This demo implements Conway's Game of Life on top of `tiles_tools`' ECS, showing ECS entity/component management, grid-aware neighbor calculations, and the crate's universal coordinate system support by running the same simulation across square, hexagonal, and triangular grids.
