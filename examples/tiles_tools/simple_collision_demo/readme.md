# Simple Collision Demo

**Keywords:** ECS, Collision Detection, tiles_tools

A minimal companion to `ecs_collision_demo`: spawns a handful of entities with `Position`/`Health`/`Collision` components on a square grid and checks which pairs collide, as the smallest possible introduction to `tiles_tools`' ECS collision system before reaching for its spatial-query and team-filtering features.
