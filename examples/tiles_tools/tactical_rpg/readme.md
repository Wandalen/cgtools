# Tactical RPG

**Keywords:** Tactical Combat, Hexagonal Grid, ECS, Pathfinding, AI, tiles_tools

A turn-based tactical RPG combat demo on a hexagonal grid: initiative-ordered turns, movement and attack ranges, and AI-controlled enemies that choose targets and act on their turn. Uses the crate's `ecs-systems` and `pathfinding-algorithms` features together and references `hecs::Entity` directly for unit handles.
