# Render Stack: d2

Planar rendering with declarative export. Everything the stack draws stays
expressible as a resolution-independent document, and layering is a property
of the command stream, not of GPU state. Sibling of [d3](003_d3.md);
extended by [tile](002_tile.md).

### Scope

- **Purpose**: The d2 stack's identity card — its full invariant table, what it renounces, and which crates live in it.
- **Responsibility**: Aggregate the stack's invariants with links to the crate-level instances pinning each; record membership and layer occupancy.
- **In Scope**: Stack-level identity: invariants, limitations, member crates.
- **Out of Scope**: Each invariant's statement/enforcement detail (the linked crate instances); the layer contracts themselves (see [../layer/readme.md](../layer/readme.md)).

### Invariant Table

| ID | Invariant | Pinned / evidenced at |
|----|-----------|------------------------|
| D2-1 | Planar geometry: 2D affine transforms (position, rotation, scale, skew) — no perspective | `Transform` in `module/helper/tilemap_renderer/src/types.rs` |
| D2-2 | Y-up coordinate system on every backend | [`tilemap_renderer` invariant/001](../../module/helper/tilemap_renderer/docs/invariant/001_y_up_coordinate_system.md) |
| D2-3 | Z-layer draw ordering: submission order portable; `depth` opt-in, opaque-only, where a depth buffer exists | [`tilemap_renderer` invariant/003](../../module/helper/tilemap_renderer/docs/invariant/003_z_layer_draw_ordering.md) |
| D2-4 | Vector representability: every command declarative, GPU-free, exportable | [`tilemap_renderer` invariant/004](../../module/helper/tilemap_renderer/docs/invariant/004_vector_representability_of_commands.md) |
| D2-5 | Alpha compositing via declared blend modes; per-backend support declared through `Capabilities::supported_blend_modes`, never silently redefined | `BlendMode` in `module/helper/tilemap_renderer/src/types.rs`; `src/backend.rs` |
| D2-6 | Viewport camera is pan/zoom (translate + scale); rotation is an object transform, not a camera capability | SVG viewport wrapper (`module/helper/tilemap_renderer/roadmap.md`, design decisions) |

### Renounced Capabilities

- Depth-buffer *semantics*: translucency correctness never comes from depth
  (D2-3's opaque-only clause) — no stack layer may require a depth buffer.
- HDR light transport: compositing happens in display range; no layer may
  assume values above 1.0 survive.
- Perspective projection.

A capability on this list is not a missing feature — requiring it founds a
sibling stack or routes through a bridge
([../pattern/001](../pattern/001_invariant_defined_stack.md),
[../pattern/003](../pattern/003_cross_stack_bridge_via_foundation_resources.md)).
